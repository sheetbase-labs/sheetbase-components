# Accessibility contract

Sheetbase components share one accessibility contract: every view is operable by
keyboard, every state change a pointer user can see is also announced or exposed
to assistive technology, and every visualisation has a non-visual equivalent.

## Table (`sheetbase-table`)

The grid is the deepest surface; its full contract lives in
`packages/table/docs/accessibility.md`. Summary:

- The grid is `role="grid"` with `aria-rowcount`/`aria-colcount`/`aria-busy`.
- Cells are `gridcell`, with row and column headers.
- Arrow keys navigate; Enter/F2 edit; Escape cancels; clipboard, undo/redo,
  find/replace, and clear all have keyboard bindings.
- Edits, selections, and errors announce through a polite live region; cell
  validation failures also render `role="alert"`.
- `SpreadsheetHandle.focus()` returns focus to the grid.

## Panes (`sheetbase-shared`, `PaneLayout`)

- Tab strips are `role="tablist"`/`role="tab"`; ArrowLeft/ArrowRight move
  between tabs on the focused strip.
- Pane operations are keyboard-first: Alt+Arrow joins the nearest stack in that
  direction, Alt+Shift+Arrow pulls a pane out into a split, Delete closes the
  focused pane.
- The pane-actions trigger exposes `aria-haspopup="menu"` + `aria-expanded`;
  the menu itself is `role="menu"`/`menuitem` behind a labelled backdrop.
- Layout changes announce through a visually-hidden `aria-live` region
  (`.sb-pane-live`).

## Schema editor (`sheetbase-schemaeditor`)

The canvas is fully keyboard-operable — pointer drag is not the only path.

- The canvas is a labelled `role="group"` in the tab order. Its `aria-label`
  documents the bindings.
- Each model node is a focusable `role="group"` whose `aria-label` names the
  model and its field count. Arrow keys on a focused node move selection —
  and focus — between nodes in model order.
- Enter or Space on a focused node enters move mode: arrows nudge the node
  8 canvas units (32 with Shift), Enter/Escape/Space or blur finishes the move.
  A moving node shows a dashed outline.
- With the canvas itself focused: `+`/`-` zoom, arrow keys pan the view
  (Shift for a larger step), `0` resets zoom and pan.
- Pointer navigation: the wheel zooms anchored at the cursor, and dragging
  pans — the middle mouse button anywhere, the left button on empty canvas.
  A horizontal trackpad swipe pans sideways.
- The topbar Focus toggle (`aria-pressed`) greys out models that are not on
  the selected model's upstream or downstream chain (transitively, not just
  immediate neighbours). It is a visual aid only: greyed models stay
  focusable and clickable, and the inspector's Links section carries the same
  information.
- Move start/end and the final coordinates announce through `.sb-schema-live`
  (`aria-live="polite"`).
- Plain arrow keys are free for the canvas because `PaneLayout` pane operations
  bind Alt+Arrow and Alt+Shift+Arrow only — there is no conflict.
- The import dialog is a labelled `role="dialog"` whose textarea takes focus on
  open; `cmd/ctrl+Enter` imports, `Esc` closes, the live preview announces
  through `aria-live="polite"`, and dropped `.sql` files have a keyboard
  equivalent in the "Add .sql files" button.
- Edges are drawn with one arrow marker per relation kind (reference, join,
  lineage) and the canvas legend names the kinds present.

## Explorer (`sheetbase-explorer`)

- Charts render through a chart library that emits `role="img"`,
  `aria-roledescription="chart"`, and `tabindex="0"` on the chart root.
- The `aria-label` is generated by `describeChart(spec, rowCount)` and names
  the kind, the mapped x/y fields, the aggregate, group/facet fields, and the
  plotted row count — e.g. `Bar chart of mean of result by assay, 7 rows`.
- The chart is never the only representation: the bottom panel's Data tab shows
  the plotted rows as a table. When `showPanel={false}` collapses the panel,
  a "Data table" `<details>` disclosure under the stage exposes the same table.
- Toolbar menu buttons expose `aria-haspopup` + `aria-expanded`; the bottom
  panel's resizer is a focusable `role="separator"` with arrow-key resizing and
  `aria-valuenow`; its collapse toggle exposes `aria-expanded`.
- Remote datasets show a text note where raw rows are not materialised.

## Rules engine (`sheetbase-rulesengine`)

- The dry-run counts line (`N rows · M matched`) and the apply outcome are
  polite live regions, so re-evaluations announce without moving focus.
- Applying writes requires an explicit `window.confirm` — no destructive
  action on a stray keypress.

## Advanced search (`sheetbase-advanced-search`)

- The combinator toggle is a labelled `role="group"`; field, operator, and
  value inputs each carry an `aria-label`.
- The Preview toggle exposes `aria-pressed`.

## Authoring checklist

When you add an interactive surface to any package:

1. Reachable by keyboard (tab order or a documented key binding that does not
   collide with the pane bindings above).
2. Named — `aria-label` or visible label on every control.
3. State that changes without focus moving is announced via `aria-live` or an
   existing live region.
4. Visualisations ship a table/text equivalent.
